# 🔍 Find File & Navigation Guide

Panduan navigasi cepat untuk mencari file dan mengelola jendela di Neovim kamu.

## 📂 Pencarian File & Teks (Global)
Keymap ini berfungsi di mana saja (Dashboard maupun saat sedang mengedit file).

| Keymap | Mode | Deskripsi |
| --- | --- | --- |
| **`F`** (Shift + f) | `n` | **Find File**: Mencari file berdasarkan nama di seluruh project. |
| **`R`** (Shift + r) | `n` | **Find Text**: Mencari kata/kalimat di dalam semua file project (Live Grep). |
| **`S`** (Shift + s) | `n` | **Global Search & Replace**: Mencari dan mengganti kata di seluruh file project. |
| **`r`** (kecil) | `n` | **Recent Files**: Mencari file yang baru saja dibuka. |

## 📄 Pencarian & Replace (Single File)
| Keymap | Mode | Deskripsi |
| --- | --- | --- |
| **`<leader>sr`** | `n` | **Local Search & Replace**: Hanya mencari dan mengganti kata di file yang sedang aktif. |

## 🌳 Sidebar Navigation
| Keymap | Mode | Deskripsi |
| --- | --- | --- |
| **`E`** (Shift + e) | `n` | **Toggle Explorer**: Buka/Tutup Sidebar Explorer (NvimTree/Neo-tree). |

## 🪟 Window & General
| Keymap | Mode | Deskripsi |
| --- | --- | --- |
| **`q`** | `n` | **Close Window**: Menutup jendela saat ini (Hanya jika > 1 jendela aktif). |
| **`<leader><leader>`**| `n` | **Search Files**: Alternatif lain untuk memicu Telescope Find Files. |

---
*Tips: Gunakan `S` untuk mass-replace satu project, dan `<leader>sr` untuk beres-beres di file itu saja!*
